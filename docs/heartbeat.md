# Leo heartbeat

The `Leo heartbeat` task runs `scripts/heartbeat/run.ts` every 30 minutes through S4U and logs to `~/.local/state/leo/heartbeat.log`. Each run is a cheap headless `codex exec` at level 15 (currently Luna) that runs the quick checks in the `leo/Watching.md` checklist in the vault, so what to watch and what good looks like change there, not in code. It can only escalate. If it does, a second run at level 75 (currently Sol) investigates and may act. The script only handles the lock, skipping an empty checklist, the journal, delivery and listing quiet top-level T3 sessions on the mini and the Mac for the checklist's session entry. Each finished run is reviewed once, and a sleeping Mac is skipped. Both run from the vault so this file doesn't load on every run. An `acted` result goes to `leo/log/YYYY-MM-DD.md`; only a `needs_herb` result posts to today's morning briefing thread, once per blocker. Never use T3 scheduled tasks for this: they activate a session on every run. Daily follow-ups, checkup prods and team-drift flags run in the briefing's `leo` lane, which keeps `leo/Follow-ups.md` current and may write Gmail drafts.
